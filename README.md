# SlowRush-todolist
🗂️ SlowRush

**TodoList – Productivité Tranquille** ✅

📝 **À propos**

SlowRush est une application web de gestion de tâches (TodoList) simple et efficace.  
Elle permet d’ajouter, d’organiser et de suivre vos tâches au quotidien avec une interface claire et intuitive.  
Les données sont stockées dans une base de données **MySQL**.

![Aperçu de SlowRush](sl.JPG)
![Aperçu de l'ajout d'une tache](ai.png)

📊 **Tableau de bord**  
Le tableau de bord permet de visualiser rapidement les tâches existantes et le suivi du projet sous forme de diagramme de Gantt.

➕ **Ajout d’une tâche**  
Une page dédiée permet de créer une nouvelle tâche en renseignant :
- le titre,
- la description,
- la priorité,
- la date,
- la durée,
- l’état de la tâche.

⚙️ **Fonctionnalités**
- Ajouter de nouvelles tâches.
- Définir une priorité pour chaque tâche.
- Spécifier une date et une durée en jours.
- Suivre l’état d’avancement des tâches.
- Visualiser ses tâches dans un tableau clair.
- Importer un diagramme de Gantt pour le suivi de projet.
- Stockage sécurisé des données avec MySQL.
- Interface moderne, claire et intuitive.
